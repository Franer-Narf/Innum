Propósito

Innum es una aplicación sencilla para crear listas de seguimiento. Está pensada para organizar elementos que deben revisarse, completarse o eliminarse cuando ya no hagan falta.

Su uso original es servir como lista de la compra: puedes crear una lista, añadir productos con cantidad y eliminar los elementos que ya tengas en el carrito para centrarte en lo que falta.

También puede usarse como lista general de tareas, inventario simple o cualquier conjunto de elementos que quieras controlar por separado.

¿Cómo funciona?

Inicio

Al abrir la app se muestra una pantalla inicial con el nombre y el logotipo de Innum. Después, la aplicación abre automáticamente la pantalla principal de listas.

Pantalla de listas

Esta es la pantalla principal. Muestra todas las listas que has creado.

  • Para crear una lista, escribe un título y pulsa Añadir. La app abrirá automáticamente la nueva lista.
  • Para abrir una lista existente, toca una vez sobre su nombre.
  • Para editar el nombre de una lista, mantén pulsada la lista y escribe el nuevo título en la ventana emergente.
  • Para eliminar una lista, deslízala horizontalmente hacia la derecha. Al eliminar una lista también se eliminan sus elementos.
  • Para eliminar todas las listas, pulsa Eliminar todo y confirma la acción.
  • Desde el menú superior puedes importar un archivo JSON de Innum o exportar todas tus listas.

Pantalla de lista seleccionada

Muestra los elementos guardados dentro de una lista concreta.

  • Para añadir un elemento, escribe el nombre y pulsa Añadir.
  • La cantidad es opcional. Si no introduces cantidad, se guardará automáticamente como 1.
  • Los elementos se muestran con su nombre y cantidad, por ejemplo: Manzanas x3.
  • Para editar un elemento, mantén pulsado el elemento y modifica su nombre o cantidad en la ventana emergente.
  • Para eliminar un elemento, deslízalo horizontalmente hacia la derecha.
  • El botón Eliminar todo elimina la lista seleccionada completa y vuelve a la pantalla principal de listas.
  • Desde el menú superior puedes exportar solamente la lista que estás viendo.

Pantalla de información

Es esta pantalla. Contiene una explicación del propósito de Innum y una guía de uso de sus funciones principales.

Menú superior

La barra superior permite moverse entre pantallas y acceder a funciones de importación y exportación.

  • Icono de información: abre esta pantalla de ayuda.
  • Icono de lista: vuelve a la pantalla general de listas.
  • Icono de compartir: permite exportar datos. En la pantalla de listas exporta todo; dentro de una lista exporta solo esa lista.
  • Icono de añadir: en la pantalla principal de listas abre el selector para importar un archivo JSON de Innum. Este icono no aparece dentro de una lista seleccionada.

Importar y exportar datos

Innum permite guardar tus datos en archivos JSON para conservar copias, mover información entre dispositivos o compartir listas.

  • Exportar todas las listas: desde la pantalla principal, usa el icono de compartir y elige si quieres descargar el archivo o compartirlo con otra app.
  • Exportar una lista concreta: abre la lista deseada, usa el icono de compartir y elige descargar o compartir.
  • Importar: desde la pantalla principal, usa el icono de añadir del menú superior y selecciona un archivo JSON válido de Innum.
  • Los archivos exportados incluyen el nombre de la app, la versión del esquema y los datos de listas y elementos.
  • Si importas una lista cuyo nombre ya existe, Innum crea una copia con un nombre alternativo para evitar sobrescribir tus datos.

Notas de uso

  • Los títulos de listas y nombres de elementos no pueden estar vacíos.
  • Dentro de una misma lista no se permite repetir el mismo elemento.
  • Los datos se guardan localmente en el dispositivo mediante una base de datos interna.
  • Las acciones de borrado importantes muestran una confirmación antes de continuar.
