Purpose

Innum is a simple app for creating tracking lists. It is designed to organize items that need to be reviewed, completed, or removed once they are no longer needed.

Its original use is as a shopping list: you can create a list, add products with quantities, and remove the items you already have in your cart so you can focus on what is still missing.

It can also be used as a general task list, a simple inventory, or any separated set of items you want to manage.

How does it work?

Start

When the app opens, it shows an initial screen with the Innum name and logo. Then the app automatically opens the main list screen.

List screen

This is the main screen. It shows all the lists you have created.

  • To create a list, enter a title and press Add. The app will automatically open the new list.
  • To open an existing list, tap its name once.
  • To edit a list name, long-press the list and enter the new title in the popup window.
  • To delete a list, swipe it horizontally to the right. Deleting a list also deletes its items.
  • To delete all lists, press Delete all and confirm the action.
  • From the top menu, you can import an Innum JSON file or export all your lists.

Selected list screen

This screen shows the items stored inside a specific list.

  • To add an item, enter its name and press Add.
  • The quantity is optional. If no quantity is entered, it will automatically be saved as 1.
  • Items are displayed with their name and quantity, for example: Apples x3.
  • To edit an item, long-press the item and update its name or quantity in the popup window.
  • To delete an item, swipe it horizontally to the right.
  • The Delete all button deletes the selected list completely and returns to the main list screen.
  • From the top menu, you can export only the list you are currently viewing.

Information screen

This is the current screen. It explains the purpose of Innum and provides a guide to its main features.

Top menu

The top bar lets you move between screens and access import and export features.

  • Information icon: opens this help screen.
  • List icon: returns to the general list screen.
  • Share icon: exports data. On the list screen it exports everything; inside a selected list it exports only that list.
  • Add icon: on the main list screen it opens the file picker to import an Innum JSON file. This icon is not shown inside a selected list.

Importing and exporting data

Innum can save your data as JSON files so you can keep backups, move information between devices, or share lists.

  • Export all lists: from the main screen, use the share icon and choose whether to download the file or share it with another app.
  • Export one specific list: open the desired list, use the share icon, and choose download or share.
  • Import: from the main screen, use the add icon in the top menu and select a valid Innum JSON file.
  • Exported files include the app name, schema version, and the list and item data.
  • If you import a list whose name already exists, Innum creates a copy with an alternative name to avoid overwriting your data.

Usage notes

  • List titles and item names cannot be empty.
  • The same item cannot be repeated inside the same list.
  • Data is stored locally on the device using an internal database.
  • Important delete actions ask for confirmation before continuing.
